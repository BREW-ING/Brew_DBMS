# Brew

Brew continuously pulls real-world "problem signals" from GitHub, arXiv, news, and Reddit, embeds them into a vector database, and matches them against a user's skills, team size, and time budget to recommend hackathon/side-project ideas that are actually feasible — not generic AI-hallucinated ideas. It also uses a graph database to recommend teammates whose skills complement the user's own.

For details on the project design, data flow, and database paradigms, see the [Architecture Documentation](file:///c:/Users/pavitra/Desktop/Brew/docs/ARCHITECTURE.md).
